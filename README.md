
# CLARION-SUM

AI-driven multi-document clinical summarization framework.

Datasets:
- MEDIQA (Primary benchmark)
- PubMed (Secondary benchmark)

Baselines (10):
Lead-3, TextRank, BERTSUM, BART, T5, PEGASUS, Long-T5, LED, HIBERT, LLM.

Proposed model:
CLARION-SUM — Hierarchical, fact-aware, self-refining summarizer.
